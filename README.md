# 🌿 Portfolio Site

Natomi のポートフォリオサイトです。  
Webエンジニア / ライターとしての活動内容・制作実績・スキルをまとめています。

🔗 https://www.natomi.work/

---

## 🚀 Tech Stack

### Framework
- Next.js 16 (App Router)
- React 19
- TypeScript

### Styling
- Tailwind CSS
- CSS Modules

---

## ✨ Features

- スクロールアニメーション
- スキルセクション（ホバーで詳細表示）
- Aboutセクション（モーダルカード表示）
- タイムライン（キャリア履歴）
- Google Map埋め込み
- お問い合わせフォーム（メール送信機能）
- レスポンシブ対応

---

## 🧠 設計意図

- **Next.js App Router** を採用し、将来的な拡張性を考慮
- コンポーネント分割により再利用性を意識
- Tailwindで高速なUI構築
- 動的表示部分のみ `use client` を使用し最適化
- 画像は最適化・プリロードによりUX向上
